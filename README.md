# promotezz.cc

The official central landing portal and umbrella directory for the Promotezz software collective.

## Overview

`promotezz.cc` connects and organizes the Promotezz ecosystem into a seamless, all-white minimalist interface with hardware-accelerated zoom interactions.

### Ecosystem Projects

* **[STARDEBLOATER](https://stardebloater.promotezz.cc/)** — Imperial Windows 10 & 11 Decluttering Engine. Strips background telemetry, bloatware, Edge, and optimizes OS latency.
* **[Promotezz Wiki](https://wiki.promotezz.cc/)** — Direct sublink documentation, script repository, and technical knowledge base.
* **[Packed](https://packed.promotezz.cc/)** — Official hub for curated Modrinth modpacks, custom mods, and game performance organization.
* **[LOL](https://lol.promotezz.cc/)** — Personal bio website, verified profiles, social links, and Discord presence.
* **[GitHub & Labs](https://github.com/promotezzz)** — Open-source repositories and experimental builds.

## Features

- **Minimalist Aesthetic**: Clean, all-white, distraction-free monochrome design.
- **Snappy Zoom Animations**: 0ms-latency GPU-accelerated CSS transitions with zero layout shift.
- **4-Quadrant Hub**: 25% viewport distribution for each ecosystem service.
- **Dedicated About Page**: Centered narrative and project overview accessible via the central trigger pill.
- **Zero Build Step**: Standalone static HTML5/CSS3/JS ready to deploy to Cloudflare Pages, Vercel, or GitHub Pages.

## Local Development

Run with any local web server:

```bash
# Python 3
python -m http.server 3000
```

Then navigate to `http://localhost:3000`.
